Mes études

Chaque étude est enregistrée automatiquement dans ce navigateur. Cliquez sur une ligne pour l'ouvrir.

Paramètres

Grille des forfaits ménage

Montants par séjour. Le forfait de chaque étude est choisi selon le nombre de chambres du bien ; vous pouvez toujours le modifier dans l'étude.

Commission de conciergerie par défaut

Données du marché (AirDNA, PriceLabs)

AirDNA et PriceLabs ne proposent pas d'accès automatique avec un compte gratuit. Le marché de chaque étude est donc rempli à partir des données publiques intégrées à l'outil. Avec un compte payant, collez l'export mensuel dans « Réglages avancés › Marché courte durée ».
