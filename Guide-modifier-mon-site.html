🛠️ Guide — Modifier mon site moi-même

Les Domaines de Tri Hent — mémo pratique pour Anne-Sophie

Les 3 endroits (à ne pas confondre) :
  • 💻 Votre ordinateur (+ Claude) : là où on modifie le site proprement. Les fichiers d'origine sont ici.
  • 💾 GitHub : la sauvegarde + l'historique. Invisible pour les visiteurs.
  • 🌐 Hostinger : le site en ligne, ce que le public voit. Seul Hostinger rend un changement visible.

1. Où vais-je pour modifier ?

Type de modificationOù ?
Minuscule et urgente : un mot, un numéro, un email, une faute de frappeDirectement sur Hostinger (§2) — puis prévenez Claude pour la sauvegarde
Tout le reste : texte long, mise en page, couleurs, sections, photos, styles.cssDemandez à Claude → il modifie + sauvegarde GitHub, vous téléversez sur Hostinger
⚠️ Ne modifiez JAMAIS styles.css directement sur Hostinger.
Ce fichier (l'apparence du site) est gardé en mémoire « cache » par les navigateurs : votre changement risque de « ne pas prendre » et vous croirez que ça n'a pas marché. Pour tout ce qui touche à l'apparence (couleurs, alignement, tailles), passez par Claude.

2. Éditer directement sur Hostinger (pour le texte)

  1. Connectez-vous à hpanel.hostinger.com → votre site → Gestionnaire de fichiers
  2. Entrez dans le dossier public_html
  3. Clic droit sur le fichier voulu → « Modifier » (ou l'icône <>)
  4. Appuyez sur Ctrl + F pour chercher le texte à changer
  5. Modifiez, puis cliquez sur Enregistrer (icône disquette 💾 en haut à droite)
  6. Rafraîchissez votre site avec Ctrl + F5 (rechargement forcé) → le changement est en ligne ⚡

3. Les règles d'or ✋

Ne jamais écrire le mot « gestion » (ni « gérer », « gère », « gérez »).
Ce terme est réservé aux détenteurs de la carte G. Utilisez plutôt : conciergerie, accompagnement, prise en charge, suivi, organisation.
Ne touchez qu'au texte, pas aux balises. Modifiez ce qui est entre les chevrons, jamais les <...> ni les class="...".
Exemple — dans <h3>Nos formules</h3>, ne changez que Nos formules.
Prévenez Claude après une modif faite en direct. Sinon la sauvegarde (ordinateur + GitHub) reste en retard, et un futur téléversement pourrait écraser votre changement. Un simple message : « j'ai changé X sur Hostinger, resynchronise la sauvegarde ».

4. Vos modifications courantes (exemples)

➜ Changer le numéro de téléphone

Il apparaît dans le pied de page de chaque page et dans contact.html. Cherchez (Ctrl+F) : 06 66 99 11 28 et remplacez par le nouveau numéro (à deux endroits : le texte affiché et dans href="tel:...").

➜ Changer l'adresse email

Cherchez : domaines.trihent@gmail.com (là aussi, dans le texte affiché et dans href="mailto:...").

➜ Corriger une phrase

Repérez un bout de la phrase, cherchez-le avec Ctrl+F, et modifiez uniquement les mots — sans toucher aux balises autour.

➜ Modifier le barème / le pourcentage

Dans index.html, cherchez class="taux" pour trouver le « à partir de 14 %» et le texte juste en dessous.

➜ Retravailler l'apparence (couleurs, alignement, sections entières)

👉 Ça, demandez-le à Claude. Ce sont les cas où une petite erreur peut casser la mise en page — et souvent ça touche styles.css (cache).

5. Sécurité : ne rien casser 🛟

  • Avant une grosse modif, faites une copie du fichier : dans le Gestionnaire de fichiers, clic droit sur le fichier → Copier (vous aurez un index (copy).html de secours).
  • En cas d'erreur, une corbeille (« Trash bin ») existe dans le Gestionnaire de fichiers.
  • Filet de sécurité ultime : une sauvegarde complète du site existe sur GitHub (github.com/Aelwenor/domaines-trihent). En cas de pépin, Claude peut tout restaurer.

6. Les photos (un peu plus technique)

Les photos actuelles viennent d'Internet (Unsplash) — ce sont des exemples. Pour mettre vos vraies photos plus tard, le plus simple sera de les téléverser dans un dossier images sur Hostinger et de remplacer les adresses src="...". Ça, faites-moi signe : c'est le genre d'étape où Claude vous aide efficacement.

7. Le workflow complet (quand Claude intervient)

1. Vous demandez le changement à Claude → il modifie les fichiers.
2. Claude fait le « commit + push » sur GitHub (la sauvegarde).
3. Claude vous dit quels fichiers re-téléverser dans public_html sur Hostinger.
4. Vous téléversez ces fichiers (en écrasant les anciens) → c'est en ligne. Un Ctrl + F5 force l'affichage de la nouvelle version.
